## Documentation conventions

- **Implemented** means the behavior has code in this repository; it may still need product hardening.
- **Partial** means only part of the intended behavior is present.
- **Planned** means it is a product direction, not a current capability.
- **Not available** means the current app does not provide the capability.
- **Out of scope** means it is intentionally not part of ZenTen Vault.

When behavior changes, update the relevant feature, stakeholder, and technical documentation in the same change.
