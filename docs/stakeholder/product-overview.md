# Product overview

## Purpose

ZenTen Vault helps people manage SSH credentials without tying recovery to a single vendor account. A person begins with a passphrase-protected Ed25519 OpenSSH private key for their master account. The app uses it to set up a vault, create associated accounts, and automatically recover associated accounts found after the vault is set up on another device.

## Who it is for

The intended user already understands the value of SSH keys and needs separate credentials for different services, projects, or environments. They are willing to retain their master account private key and passphrase as important recovery material.

## What the app helps a user do

- Set up a vault using an existing master account.
- Create associated Ed25519 SSH accounts.
- View an associated account's public information and, after an explicit confirmation, its private key.
- Check whether backup copies are known to be available.
- Retry a backup check when a connection or remote destination has a problem.
- Set up the vault on another device with the same master account private key and passphrase; valid discovered associated accounts are restored automatically.

## Main product promise

A user who still has their master account private key **and** its passphrase can set up the same vault identity on a replacement device. The app then looks for and automatically restores valid discovered associated accounts.

## Key concepts

| Concept | Plain-language meaning |
| --- | --- |
| Master account | The existing SSH account the user brings to setup. Its private key and passphrase are the root of recovery; the app does not generate a replacement. |
| Vault | The user's local view of generated associated accounts and backup status. |
| Associated account | A new SSH account generated by the app for a separate use. It is identified by its creation ID. Technical material may call this a *associated account*. |
| Backup destination | A configured remote service where the app attempts to store a protected backup copy. |
| Backup status | The latest information the app has about a backup's presence or condition. |
| Automatic recovery | The app brings every valid discovered associated account into the local vault during recovery; it does not ask the user to choose accounts individually. |

## Product boundaries

ZenTen Vault is not an SSH terminal, SSH agent, Git client, general password manager, or account-registration service. It does not recover a lost master account private key or a forgotten passphrase. The current app does not provide account deletion or vault-reset actions.

## Current maturity

This repository is a proof of concept. Stakeholders should use the [scope and roadmap](scope-and-roadmap.md) to distinguish current implementation from intended product behavior. It must not be represented as a production-ready credential vault without further security review and release work.
